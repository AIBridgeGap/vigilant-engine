# CURRENT_WEBSITE

This directory contains the active working version of the AIBridgeGap.com website.

## Directory Structure

### 📄 PAGES/
Contains all HTML pages for the website:
- `index.html` - Homepage with hero section and service overview
- `services.html` - Detailed services page
- `about.html` - About page with company information
- `contact.html` - Contact page with form and information
- `demos.html` - AI demos and interactive examples
- `blog.html` - Blog/resources page
- `privacy_policy.html` - Legal privacy policy page

### 🎨 ASSETS/
Website assets organized by type:

#### CSS/
- `styles.css` - Main stylesheet with all website styling

#### JS/
- `script.js` - Main JavaScript functionality
- `demo-scripts.js` - Interactive demo functionality

#### IMAGES/
- Hero images and graphics for the website

### 📋 DOCUMENTATION/
- `AIBridgeGap_Website_Documentation.md` - Complete website documentation
- `cPanel_Upload_Instructions.md` - Deployment instructions for cPanel

### 🔧 DEPLOYMENT_READY/
Contains deployment-ready copies of all website files organized for cPanel upload.

## Usage

This is the primary working directory for website development and maintenance. All active development should be done on files in this directory structure.

For deployment, use the files in the DEPLOYMENT_READY subdirectory.
