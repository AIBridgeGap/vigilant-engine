# ALTERNATIVE_VERSIONS

This directory contains alternative implementations and versions of the AIBridgeGap.com website.

## Directory Structure

### NEXTJS_VERSION/
Contains the Next.js implementation of the website:
- Complete React/Next.js codebase
- Tailwind CSS styling
- Modern development setup with TypeScript
- Component-based architecture

### LANDING_PAGE_VERSION/
Contains temporary landing page implementations:
- Simple HTML/CSS landing pages
- Placeholder content and styling
- Quick deployment options

## Usage

These directories contain alternative implementations that are not actively used but preserved for reference and potential future use.

- **NEXTJS_VERSION**: Modern React-based implementation
- **LANDING_PAGE_VERSION**: Simple placeholder landing pages

The current active website is maintained in the CURRENT_WEBSITE directory.
