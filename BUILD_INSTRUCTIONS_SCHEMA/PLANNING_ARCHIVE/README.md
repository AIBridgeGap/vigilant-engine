# PLANNING_ARCHIVE

This directory contains historical planning documents, templates, and development guides.

## Directory Structure

### V1_PLANNING/
Contains the original v1.0 planning structure:
- Phase-based development plans
- Content templates and instructions
- Hero images and design assets
- Step-by-step implementation guides

### DEVELOPMENT_PLANS/
Contains high-level development planning documents:
- Website development plans and strategies
- Version control and planning documents
- Architectural decisions and approaches

### SUPER_CLAUDE_SCRIPTS/
Contains AI assistant scripts and templates:
- Super Claude enhancement scripts
- AI training service page templates
- MCP integration guides
- Automation and enhancement tools

## Usage

These files represent the historical development process and planning materials. They are preserved for:
- Reference during future development
- Understanding the evolution of the project
- Reusing templates and proven approaches
- Learning from past development decisions

Current active development should reference these materials but work from the CURRENT_WEBSITE directory.
